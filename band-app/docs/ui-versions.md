Решение на потребителя (2026-09-26): екранът „Старт“ също се обновява. Layout-ът от v2 остава (размери,

  на класовете `tr-play-idle` / `tr-play-run`; цветът остава резервен
- Ореолът зад play: статично изпечено сияние `glow-train*`, центрирано върху бутона (кутията е 16 px над него) —
  **без** безкрайната анимация „breathe“ (последната в приложението)
- Главна лента − / +: градиент, шев и светъл ръб (`gen-all-btn.py`); пауза = същото изображение с `.cfill-dim`
  (прозрачност 0.62) — едно изображение в паметта вместо две
- Каналите: редът е тъмна карта (`#17181C`), запълването е нивото; на живо тоновете са по-наситени
  (`FILL_LIVE`), стойността е бяла — четим текст
- Стопът остава CSS (изпечена повърхност би надхвърлила бюджета от 480 KB; сега 445 KB)
