XEMS Branding — Dev Reference

Статичен hub за YAML карти и команди. Основна документация: DEVELOPMENT.md

Build: bash build-apk.sh (стабилен, login-safe)
Custom train layout: DESIGN_PIPELINE=1 bash build-apk.sh (само тест)

Документация

DEVELOPMENT.md

Ръководство за разработка — pipeline, train row, контроли, правила, agent checklist

YAML карти

ui-map.yaml

Екрани, train row колони, критични @id, build pipeline, config_to_xml

 train-controls-map.yaml

Пълен каталог на контроли, BLE път, parallel API, TrainControlBridge proposal

 design-config.yaml

Числови размери на train row — редактирай директно, после apply-design-config.py

 design-presets.yaml

Готови профили: phone, tablet, tablet_wide

Команди

python3 scripts/ui-map.py --check
python3 scripts/apply-design-config.py --check
python3 scripts/apply-design-config.py
bash scripts/design-apply.sh [--preset tablet] [--import FILE.yaml]
bash build-apk.sh
