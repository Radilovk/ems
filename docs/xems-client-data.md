# XEMS — какви данни къде живеят

Три нива: **таблет** (всичко, само при студиото), **споделяне** (файл, който треньорът изпраща
ръчно) и **уеб** (картонът на клиента по линк). Нищо не излиза от таблета без действие на треньора.

## 1. Само на таблета

| Какво | Къде |
|---|---|
| Запис на всяка тренировка секунда по секунда: сила по 10 зони, Hz, µs, импулс/пауза, пулс, фази | `files/xems_sessions/` (`SessionStore`) |
| Профил на клиента: пол, възраст, тегло, ръст, форма, цел, пулс в покой, снимка | базата на приложението, `AiProfile` |
| Пълният отчет: ход на тренировката, режими на тялото, параметри по фази, оценка и формулите | `session-report.html` (рисува се на таблета) |
| Дневници на гривната и приложението | `diag-logs/` |

## 2. Споделяне (треньорът изпраща файл; след това файлът е при получателя)

| Файл | Съдържа |
|---|---|
| Картина (1080×1920) | извод, 4 числа, ход на тренировката, мускули — **една тренировка** |
| PDF | отчетът на избрания изглед (кратък/пълен) — **една тренировка** |
| Кратко съобщение | текст с резултатите — **една тренировка** |
| TCX | тренировката с пулса — за Strava, Garmin, TrainingPeaks |
| CSV по секунди | целият запис на тренировката |
| CSV история | по един ред на тренировка, всички тренировки |

## 3. Уеб — клиентският картон (`/c/<id>` на сървъра)

Качва се само след като треньорът веднъж изпрати „Клиентски картон · линк“. След това линкът се
обновява **сам** всеки път, когато отчетът на клиента се отвори с нова тренировка (в края на всяка
тренировка отчетът се отваря) — `ReportBridge.refreshCard`. Един клиент има един и същ линк.

Съдържа само (`cardData()` в отчета):

| Изглед | Данни |
|---|---|
| **Всичко** | брой тренировки, часове, kcal, натоварване по мускули, ефективност на последните 24, тренировки по седмици (12), поредни седмици |
| **30 дни** | брой, часове, kcal, натоварване по мускули, ефективност |
| **Последна** | дата, програма, активно време, kcal, ефективност, среден пулс, натоварване по мускули |

Първо име и пол (за фигурата). **Не** се качват: фамилия, възраст, тегло, ръст, снимка, записи по
секунди, пулсова крива, фази и настройки на костюма. Линкът изтича 365 дни след последното
обновяване, не се индексира от търсачки. Без сървър или без интернет таблетът праща картона като
HTML файл (тогава той е снимка към момента и не се обновява).
