Health Icons (https://healthicons.org, github.com/resolvetosavelives/healthicons), outline set, **CC0 1.0** (public
domain). Red line icons like XBody's own program-selection tiles; `scripts/xbody/gen-panel-art.py` paints them
XBody red (#E21A22) into `xbody/overlay/opt/xems/art/<program id>.png`.
